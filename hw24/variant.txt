Part A - Variant helpers

1. A struct gives each member its own memory, but a union makes all the members share the same memory. So only one can hold a valid value at a time.

2. After set_score, the memory holds an int. If I try to read value.average, it reads those same bytes as a float, so I would get a weird number instead of the score.

3. The kind field tells the program which union member is being used (STAT_SCORE or STAT_AVERAGE), so it knows which one is safe to read.

4. They check the kind first so they dont read the wrong member. If it doesnt match, they just return 0 instead of getting some garbage value.

5. It shows that the union members all share the same bytes. The union only needs enough space for its biggest member (4 bytes), but the struct needs space for both fields (8 bytes).
